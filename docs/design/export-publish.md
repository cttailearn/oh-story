# oh-story WebUI 导出与发布对齐（v0.1）

> 对接 [`api-contract.md`](api-contract.md) `POST /export`。目标：**把"能看的书"变成"能传的稿"**——格式/字数口径/章节规整与主流平台对齐，导出即审稿成品。

---

## 1. 导出形态（递增）
| 形态 | 内容 | 用途 |
|---|---|---|
| Markdown 单册 | 正文（含/不含细纲设定，开关） | 自己归档、二次编辑 |
| 纯文本 .txt | 平台裸稿（分卷/分章/无 markdown 符号） | **起点/番茄/晋江/盐言 主投** |
| 分卷 ZIP | 每卷一文件夹 + `README.txt`（封面引用/字数统计） | 投稿打包 |
| Excel 清单 | 章节/字数/首尾钩子/三查状态 表格 | 数据自检 |
| **epub**（M4+） | 阅读器成品（内嵌封面/分卷/目录） | 自读/分发 |

---

## 2. 平台对齐表（文本规范）
| 平台 | 章节标题 | 换行 | 敏感点提示 |
|---|---|---|---|
| 起点 | `第X章` 或 `第X回`，卷首居中 | 段间空行 1；全角标点 | 涉政/涉军/暴力分级 |
| 番茄 | `第X章 标题` 一行 | 段间空行 1；无缩进 | 爽点密度/系统文规范 |
| 晋江 | `第X章`，正文 2 字缩进 | 段间空行 | 感情线/热度（红字预警） |
| 盐言（短篇） | 标题 + 分段 | 短句多、段短 | 反转强度/情感共鸣 |
- 转换规则抽成 `server/export/formatters/{txt-start, txt-fanqie, txt-jj, txt-yanyan, markdown}.ts`，共用清洗管线：
  - 去 markdown 语法（`#`/`**`/链接/代码块）；
  - 全角标点归一化；空行规范化；
  - 章节编号重排（连续、卷转移至卷首）；
  - 特殊字符转义（书名号引号平台兼容）。

---

## 3. 字数统计口径（与平台对齐，避免"后台 3 万、发布 2 万"落差）
- **口径定义**：`正文.md 去空行去空白符号后的 Unicode 字符数 - 常见标点（，。！？；：""''（））`——采用「平台侧近似（纯字符数）」与「网文惯例口径（扣标点）」双口径展示。
- 导出时按所选平台给出**预期上架字数**（±5% 提示：若目标 2000/章，导出按口径校低于 1800 时标红）。
- 覆盖率：`已写章节 / 计划章节`、净可用字数、均章字数。

---

## 4. 封面 / 图 / 版权
- `封面/` 与 `角色卡图/` 可选随包嵌入（ZIP 复制文件；epub 内嵌二进制）。
- 生成 `版权.md` / `致谢.md` 可选附页；默认不自动生成（作者决定）。
- 导出审计 `audit{action:'export', target:'book:nb_02K/md，口径:字符数'}`。

---

## 5. 发布前检查（导出阶段的软门禁）
| 检查 | 性质 | 说明 |
|---|---|---|
| `delivery-contract` 全章节过 | blocking | 每章形态合法 |
| 去AI味报告 | warning | 导出时重新跑 ai-patterns + 给出全本 blocking 计数 |
| 章节编号连续 | blocking | 有缺号/乱序则拒导并提示 |
| 目标字数达标 | warning | 按平台口径换算 |
| 追踪状态未带"严重风险" | warning | 存在未收伏笔不影响发布，仅提示 |

- 全部 blocking 清零才允许「导出并打包」；warning 提示后仍可导出（作者决定）。

---

## 6. 实现要点
- `POST /export {format, platform?, include:[chapters,outline], images?:boolean}` → 后台 job（进度 SSE）→ 产物落 `{书}/交付/` → 返回下载链接（同源静态下载，含 24h 清理）。
- 导出不修改 `_tracking-state.json`；可重复导出（幂等键）。
- `markdown` 默认含 `正文/` 全部正式 Revision（仅"正式"标识，非 `_rev` 草稿）。

---
