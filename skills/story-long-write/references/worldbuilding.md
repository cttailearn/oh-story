# 世界观构建与规则边界

世界观不是背景板，是正文可执行的**规则集合**。本文档给出力量体系设计、规则边界四要素与层级结构的方法，配合 artifact-protocols.md 的「世界观卡」模板落盘。

## 1. 力量体系设计（三问）

1. **来源**：力量从哪里来（灵气/系统/血脉/科技）？来源决定上限与代价的类型。
2. **台阶**：共几档？每档解锁什么能力、什么社会地位？档数 × 每档篇幅 ≥ 全书目标字数，档间要有质变（不只是数字变大）。
3. **代价与限制**：使用力量的代价（寿命/资源/反噬）和硬限制（次数/环境/对象）。**没有代价的力量体系会让冲突失效**——读者不信角色会遇到真正的困难。

**防写崩原则**：

- 每档能力的"能做什么/不能做什么"至少各写一条，不能只写"更强"
- 新能力解锁必须挂在剧情节点上（境界突破=剧情奖励），不凭空升级
- 力量与社会结构联动：高境界者承担什么义务、受什么约束，避免"无敌流"失去对抗张力

## 2. 规则边界四要素

每条世界观规则都必须能回答四问，缺一问就是留给正文的"漏洞"：

| 要素 | 含义 | 示例（传送阵规则） |
| --- | --- | --- |
| **规则** | 规则本身的陈述 | 传送阵只能传送死物 |
| **适用条件** | 什么情况下生效/不生效 | 仅限境内城池之间 |
| **例外与代价** | 例外情况 + 突破例外的代价 | 活体传送需上界敕令+三成修为 |
| **层级归属** | 世界级/势力级/个人能力/一次性道具 | 世界级规则，任何个人能力不得覆盖 |

**边界检查口诀**：正文出现"按规则应该不能发生却发生了" → 要么有例外来源（敕令/代价/前文证据），要么是设定冲突（S2），必须修文或补设定，不允许"忘了这条规则"。

## 3. 设定层级结构

```text
世界级规则（物理法则/天道/大境界上限）
  └─ 势力级规则（宗门制度/行业规矩/家族禁令）
      └─ 角色个人能力（金手指/功法/天赋）
          └─ 一次性道具效果（法器/丹药/机缘）
```

- **下位不得无解释覆盖上位**：局部例外必须有来源、代价或章节证据
- 金手指属于个人能力层，不能推翻世界级规则，只能在世界级规则内找到缝隙
- 新设定与已有设定冲突时，先查层级：上位改下位需要全书级理由（终局底牌），下位改上位只是正常剧情

## 4. 硬事实表规范

每张设定卡（角色/势力/世界观）末尾附「硬事实表」，供写作与一致性检查 grep 锚定：

```text
硬事实表（只写不变事实，可变状态归追踪）：
  传送阵: 只传死物；活体需上界敕令
  境界: 筑基|金丹|元婴|化神（4档）
  灵石: 通用货币，下品/中品/上品 1:100
```

- **单行 key: value** 写法，`key` 是唯一术语，`value` 是这条设定的一行结论
- 正文写作时如引用该设定，按行核对；一致性检查直接 grep `key` 与正文比对
- 硬事实表只写不变事实；"当前境界""已解锁能力"等推进态归追踪，不写进表里

## 5. 世界观卡与角色卡「剧情线」的关系

- 世界观卡管**世界怎么运转**（规则），角色卡「剧情线」标题管**角色经历什么**（剧情），角色卡其它标题管**角色是谁**（人设）
- 世界观规则在正文中的解锁顺序（何时向读者揭示哪条规则）记在角色卡「剧情线」各阶段的「解锁/伏笔」条目里，与终局底牌联动
