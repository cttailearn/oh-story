# 审查记录契约（review-log）

> 语义审查（写入审查 write-review / 大纲安全审查 / 七检）必须有**落盘产物**：审查记录文件。
> **「审查记录缺失 = Gate 未完成 = 不得报告完成」**——这是完成定义的一部分，不是可选项。
> 机械校验（脚本）与语义审查（记录）缺一不可：产出 ✓ + 机械校验 ✓ + 审查记录 ✓ 三元组齐备才算完成。

## 文件位置与命名

- 目录：`大纲/审查记录/`（自动创建）
- 命名：`{类型}.md`——`设定审查.md`（Gate A 后）、`大纲审查.md`（Gate B 后）、`细纲审查_第{batch}批.md`（Gate C 后，按批累计）、`正文审查_第{章}.md`（正文阶段可选）

## 固定模板（每份记录必含以下栏目，栏目缺失即视为未完成）

```markdown
# {类型}审查 — {日期}

- 审查范围：{本次写入的文件清单}
- 执行方式：{agent（consistency-checker）/ solo}

## 逐项检查（对应清单逐条，禁止"整体没问题"式概括）

- [ ] {检查项 1}：{判定 + 依据（引用的文件/行）}
- [ ] {检查项 2}：{判定 + 依据}

## 发现（S1-S4 分级）

- [S级别][类别] {描述}；出处：{文件}；处置：{已修/待用户确认/忽略及理由}

## 结论

- S1/S2：{已全部落实（列修改的文件）/ 未落实（阻塞，不得进入下一步）}
- S3/S4：{列出待确认项}
